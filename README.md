# 🧠 BrainWave Quiz Application

BrainWave Quiz Application is a web-based quiz platform where users can participate in quizzes and test their knowledge, while administrators can create, manage, and organize quizzes efficiently. The system includes separate roles for Admins and Users, ensuring secure and structured quiz management.

## 🚀 Features

### 👨‍💼 Admin Features

* Create new quizzes
* Add, edit, and delete questions
* Manage quiz categories
* View quiz results and user performance
* Control and update quiz content
* Secure admin access 

### 👤 User Features

* Register and log in
* Attempt available quizzes
* View scores after quiz completion
* Track quiz performance
* User-friendly quiz interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* React.js 
* Node.js
* Express.js 
* MongoDB / Database 

## 📋 How It Works

1. Admin logs in to the dashboard.
2. Admin creates quizzes and adds questions.
3. Users log in to the platform.
4. Users select and attempt quizzes.
5. The system evaluates answers automatically.
6. Users receive their scores and results instantly.

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/BrainWave-Quiz-Application.git
```

2. Navigate to the project directory:

```bash
cd BrainWave-Quiz-Application
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```
